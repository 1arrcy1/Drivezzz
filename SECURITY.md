# Security

Found a weakness in Drivezzz, the escrow program or this code? Email info@s3rver.nl with what you found and how to see it again. Please give us time to fix it before you tell others.

Test against a copy you run yourself, never against Drivezzz's live servers, its users or real escrows: `README.md` (Running it) and `docs/escrow.md` say how to run the server and the program on your own machine or on devnet.

Never send keys, recovery words or other people's data, also not in an issue or a pull request.
